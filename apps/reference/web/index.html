EquityGuard

Economic-intent protection for tokenized stocks.

A transaction prepared under one economic state should not silently execute under another.

Built for wallets, trading apps, agents, and tokenized-asset infrastructure.

Reference app. Decisions are precomputed at build time by EquityGuard's guard model and decision engine over recorded Solana mainnet state, and cross-checked against a local-validator replay. Nothing here runs on mainnet, signs a transaction or moves funds. EquityGuard is deployed on devnet only and has not been externally audited.
