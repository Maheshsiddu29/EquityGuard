Integration

Jupiter builds. EquityGuard protects. Wallet signs.

const build = await buildJupiterSwap({ quote, userPublicKey });
const protectedSwap = await protectJupiterSwap({
  build, userPublicKey, rpc,
  protectionWindow: { beforeSecs: 60, afterSecs: 60 },
});

if (protectedSwap.status === "PROTECTED") {
  await wallet.signAndSendTransaction(protectedSwap.transaction);
}
What this demo does not prove · limitations and technical details

Devnet deployment only. EquityGuard running on mainnet, or a real purchase. It is deployed on devnet only.

Separate test. Not the Sep 15 event. A trade that crossed the Sep 15 event. The local replay ran two days later.

Devnet boundary. A guarded Jupiter trade on devnet is not claimed; Jupiter is unavailable there.

Illustrative route. Illustrative. Not a real reroute. A real cross-issuer reroute was not demonstrated.

Uncalibrated windows. The 15 min / 5 min protection window is an uncalibrated demo value.

Review status. EquityGuard has not been externally audited.

Real source. Recorded read-only from Solana mainnet; the execution replay used a local validator.

Strict support. Unsupported state semantics and Jupiter route shapes fail closed.

Scalar state model. Mergers, spinoffs, and legal identity are outside the current model.

Upgrade risk. The reviewed devnet program can be upgraded after client attestation and before landing.

Package status. The SDK packages are currently unpublished.
