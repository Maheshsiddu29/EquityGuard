Execution-time corporate-action safety

Slippage protection, but for corporate actions.

A tokenized equity's economic state can change between the quote, the signature and the moment the transaction lands. EquityGuard moves that check into execution time, in the same transaction as the trade.

Run the protected trade→ Read the documentation
The invariant

A transaction constructed against economic state S must not execute successfully if the relevant protected economic state has changed to S′ before execution.

●State unchanged · executes ■State changed · fails atomically
